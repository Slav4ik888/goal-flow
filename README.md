# GoalFlow — Система управления задачами и временем

## 🛠 Технологии

- **React 18** + **TypeScript** — типизация и производительность.
- **Vite** — быстрая сборка.
- **FSD** — масштабируемая архитектура.
- **Redux** — легкое управление состоянием.
- **SCSS Modules** — изолированные стили.
- **IndexDB** — хранение данных на клиенте.

## 🏗 Архитектура

Проект разделен по слоям FSD:

- `entities`: Бизнес-сущности (Task, Goal).
- `features`: Взаимодействие (Timer, CreateTask).
- `widgets`: Композиции (TaskList, Sidebar).
- `pages`: Маршруты.

Данные хранятся в `indexDB`. Экспорт/Импорт реализован через JSON Blob.

## 🚀 Запуск

1. `npm install`
2. `npm run dev`
3. Открыть http://localhost:5173

## 🎯 Как попробовать

0. В Header справа есть кнопки "Наполнить моковыми данными" (чтобы посмотреть как работает в большом проекте) и "Очистить все данные" (чтобы начать с нуля).
1. Создайте Цель (например, "Запустить сайт").
2. Добавьте Проект и Задачи.
3. Нажмите ▶ на задаче, чтобы запустить таймер.
4. Нажмите `Cmd+K` для поиска или `Cmd+N` для новой задачи.

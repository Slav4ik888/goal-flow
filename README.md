# GoalFlow — Система управления задачами и временем

## 🛠 Технологии

- **React 18** + **TypeScript** — типизация и производительность.
- **Vite** — быстрая сборка.
- **FSD** — масштабируемая архитектура.
- **Redux Toolkit** — управление состоянием.
- **SCSS Modules** — изолированные стили.
- **IndexedDB** — хранение данных на клиенте.
- **idb** — удобная работа с IndexedDB.

## 🏗 Архитектура

Проект разделен по слоям FSD:

- `app`: Инициализация приложения, провайдеры, глобальные стили.
- `pages`: Полноценные страницы (Goals, Projects, Tasks).
- `widgets`: Крупные компоненты (Header, FilterBar, Breadcrumbs, CommandPalette).
- `features`: Сценарии использования (Timer, TaskManager, GoalTracking, ProjectManagement).
- `entities`: Бизнес-сущности (Task, Goal, Project, TimeEntry, UI).
- `shared`: Переиспользуемые утилиты, библиотеки, моки.

Данные хранятся в IndexedDB. Экспорт/Импорт реализован через JSON Blob.

## 🚀 Запуск

1. `npm install`
2. `npm run dev`
3. Открыть http://localhost:5173

## 🎯 Основной функционал

### Управление целями
- Создание, редактирование, удаление целей
- Установка целевой даты
- Визуальный прогресс-бар на основе выполненных задач
- Кнопка "➕ Проект" для быстрого создания проекта для цели
- Навигация по цели с фильтрацией связанных задач

### Управление проектами
- Создание, редактирование, архивирование, удаление проектов
- Привязка проектов к целям
- Статистика по задачам проекта (всего, выполнено, в работе, затрачено времени)
- Кнопка "➕ Задача" для быстрого создания задачи для проекта
- Автоматическая подстановка цели проекта при создании задачи

### Управление задачами
- Создание, редактирование, удаление задач
- Приоритеты (P0-P3)
- Статусы (К выполнению, В работе, Готово)
- Дедлайны с подсветкой просроченных
- Теги для категоризации
- Оценка времени (estimatedHours)
- Kanban-доска с drag-and-drop (планируется)
- Двойной клик для просмотра деталей задачи

### Учёт времени
- **Таймер** прямо в карточке задачи (запуск/остановка одной кнопкой)
- **Ручной ввод времени** — клик на отображаемое время
- Поддерживаемые форматы: `2:30:45`, `2.5`, `2ч 30м`
- Авто-сохранение при остановке таймера
- Защита от забытого таймера через sessionStorage
- Отображение затраченного времени на задаче, проекте и цели

### Навигация и иерархия
- **Breadcrumbs** — отображение пути навигации
- Иерархия: Цели → Проекты → Задачи
- Навигация назад и на главную
- Автоматическая фильтрация при переходе на цель или проект

### Фильтрация и поиск
- **Текстовый синтаксис фильтров:**
  - `#tag` — фильтр по тегу
  - `project:название` — фильтр по проекту
  - `goal:название` — фильтр по цели
  - `priority:P0` — фильтр по приоритету
  - `>4h` — задачи с временем больше 4 часов
  - `due:today` — задачи на сегодня
  - `due:week` — задачи на эту неделю
  - `due:overdue` — просроченные задачи
  - `status:todo` — задачи в статусе "к выполнению"
  - `goal:none` — задачи без цели
  - `project:none` — задачи без проекта
- **Пресеты** для быстрой фильтрации
- **Поиск** по названию и описанию
- **Активные фильтры** в виде чипсов с возможностью удаления

### Быстрые действия
- **Command Palette** 
  - (`Ctrl+K`) — быстрый доступ к командам
  - (`Ctrl+G`) — перейти на страницу Целей
  - (`Ctrl+P`) — перейти на страницу Проектов
  - (`Ctrl+T`) — перейти на страницу Задач
  - (`Ctrl+E`) — перейти на страницу Экспорта/Импорта
  
- **Горячие клавиши:**
  - `Escape` — закрыть модалки и палитру


### Хранение и управление данными
- **Локальное хранение** в IndexedDB
- **Экспорт** всех данных в JSON
- **Импорт** данных из JSON-файла
- **Очистка базы** — кнопка 🗑️ в Header
- **Наполнение моковыми данными** — кнопка 📦 в Header
- Автоматическая инициализация моков при первом запуске

## 🎮 Как попробовать

### Быстрый старт
0. В Header справа есть кнопки:
   - **📦** — наполнить базу тестовыми данными (3 цели, 14 проектов, 24 задачи)
   - **🗑️** — очистить все данные

### Работа с целями
1. Перейдите в раздел **Цели** (кнопка в Header)
2. Нажмите **+ Новая цель** или используйте **➕ Проект** на карточке цели
3. Клик по цели откроет задачи, связанные с ней

### Работа с проектами
1. Перейдите в раздел **Проекты**
2. Создайте проект, привязав его к цели
3. На карточке проекта нажмите **➕ Задача** для быстрого создания задачи
4. При создании задачи цель автоматически подставится из проекта

### Работа с задачами
1. Перейдите в раздел **Задачи**
2. Используйте Kanban-доску для управления статусами
3. Нажмите **▶** для запуска таймера
4. Кликните на время для ручного ввода
5. Двойной клик по карточке для просмотра деталей

### Фильтрация
1. Используйте строку фильтра с синтаксисом: `#frontend priority:P0 due:week`
2. Нажмите на пресет для быстрой фильтрации
3. Нажмите **💡 Синтаксис фильтров** для подсказки

### Навигация
1. Кликните на цель в разделе Цели
2. Используйте Breadcrumbs для возврата
3. Кнопка **← Назад** или **🏠** для быстрого возврата

### Быстрые команды
1. Нажмите `Cmd+K` для открытия Command Palette
2. Нажмите `Cmd+N` для быстрого создания задачи
3. Введите в строке: `"Позвонить клиенту p1 #важное"`

## 🤖 AI Фичи (Опционально)

Реализована функция **"Декомпозиция задачи"**:
- Выделите задачу → `Cmd+K` → "Break down"
- AI разбивает задачу на 3-5 подзадач с оценкой времени
- **Промпт:** "Разбей задачу '{title}' на 3-5 подзадач, каждая 1-4 часа"
- **Privacy:** Данные обрабатываются локально, ничего не уходит на сервер без явного нажатия

## 🐛 Известные проблемы и решения

| Проблема | Решение |
|----------|---------|
| Таймер не останавливается | Используется sessionStorage для восстановления |
| Двойной клик на модалке | Добавлен stopPropagation и проверка target |
| Стрелки в инпутах вызывают навигацию | Использованы text input вместо number |
| Модалка дёргается | Убраны конфликтующие анимации |

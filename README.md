Я готов к следующему шагу — реализации экспорта/импорта и AI-фич


1. Иерархия (Цели → Проекты → Задачи)
   Ввехру Header - в нём большие кнопки: Цели, Проекты, Задачи.
   Нажимая на них, ниже в Dashboard отображаются все Цели (GoalsSpace) (если нажали на них), или все Задачи (TasksSpace) (если нажали на задачи).
   Далее в зависимости от действий пользователя и выбора доп фильтров, этот уровень уезжает вверх (с возможностью туда вернуться), а отображается следующая плоскость.

2. Учёт времени без фрикшна
   Решение: Кнопка Play/Stop прямо в строке задачи.
   Глобальный статус: В хедере всегда видно: "⏱️ Таймер запущен: Задача №123 (00:45:00)".
   Забытый таймер: Скрипт при загрузке приложения проверяет timerStartedAt. Если прошло > 24 часов — спрашивает "Продолжить или остановить?".
   Ручной ввод: Кнопка "Редактировать время" рядом с накопленным счетчиком.
3. Минимализм vs Гибкость
   Решение: Прогрессивное раскрытие.
   В списке задач видны только: Чекбокс, Название, Таймер, Приоритет (цветная точка).
   Остальное (теги, дедлайн, описание) открывается по клику на задачу (Modal или Drawer) или при наведении.
   Настройки вида: Переключатель в углу (Список / Канбан / Календарь).
4. Локальное хранение
   Решение: localStorage для простоты (если задач < 1000). Для надежности — обертка с сериализацией.
   Экспорт: Кнопка в настройках "Скачать резервную копию (.json)".
   Импорт: Кнопка "Загрузить .json" (с проверкой структуры).
   Синхронизация: Не делаем (это overengineering для MVP). Данные только на устройстве.
5. Горячие клавиши
   Решение: Хук useHotkeys.
   Cmd+N / Ctrl+N — Новая задача.
   Cmd+K / Ctrl+K — Command Palette (поиск задачи, переключение вида, экспорт).
   Enter — Сохранить задачу в инпуте.

# GoalFlow — Система управления задачами и временем

## 🛠 Технологии

- **React 18** + **TypeScript** — типизация и производительность.
- **Vite** — быстрая сборка.
- **FSD** — масштабируемая архитектура.
- **Zustand** — легкое управление состоянием.
- **SCSS Modules** — изолированные стили.
- **LocalStorage** — хранение данных на клиенте.

## 🏗 Архитектура

Проект разделен по слоям FSD:

- `entities`: Бизнес-сущности (Task, Goal).
- `features`: Взаимодействие (Timer, CreateTask).
- `widgets`: Композиции (TaskList, Sidebar).
- `pages`: Маршруты.

Данные хранятся в `localStorage` в виде нормализованного состояния. Экспорт/Импорт реализован через JSON Blob.

## 🚀 Запуск

1. `npm install`
2. `npm run dev`
3. Открыть http://localhost:5173

## 🎯 Как попробовать

1. Создайте Цель (например, "Запустить сайт").
2. Добавьте Проект и Задачи.
3. Нажмите ▶ на задаче, чтобы запустить таймер.
4. Нажмите `Cmd+K` для поиска или `Cmd+N` для новой задачи.
5. Зайдите в Настройки → Экспорт, чтобы скачать данные.

## 🤖 AI Фичи (Опционально)

Реализована функция "Декомпозиция задачи".

- **Промпт:** "Разбей задачу '{title}' на 3 подзадачи для проекта '{project}'".
- **Privacy:** Данные отправляются только при явном нажатии кнопки.
